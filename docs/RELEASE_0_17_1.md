# AutoBoxV 0.17.1

Corrige as duas janelas abertas na versão 0.17.0. Mapa, configurações e estatísticas agora ficam em uma única janela, com navegação por abas. Os botões Config. e Estatísticas levam à seção correspondente dentro do mesmo aplicativo. Ao abrir, o bot mostra sempre o mapa novo, mesmo com preferências antigas.

A alternância de abas preserva os trabalhadores e configurações do farm. Controles e informações anteriores continuam acessíveis na aba Configurações e estatísticas.

Validação local: 260 testes, incluindo interface gráfica, com a mesma exclusão do teste de certificados específica do runtime local. O workflow Windows executa todos os testes e verifica o executável antes de atualizar o manifesto.
